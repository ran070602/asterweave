棋盘上的黑格是夜空里的星：**数字**告诉你周围 8 格有几颗星（扫雷），**上方/左侧的数字**告诉你这一列/行里"连续的星"有多长（数织）。翻开所有安全格、并把所有星都标出来即通关；3 条命，踩到未标记的星会掉一条。通关后会揭晓本关对应的**真实星座**——棋盘上那些不属于星座的"杂星"不参与连线。

## 特性

- **两套机制真正咬合**：88 关全部"只用扫雷数字解不完"，必须结合数织线索；第 1 关就引入数织：只给最直白的连续块线索（本关是第 5 列 `4` 连、第 3 行 `2 1`）带着玩。
- **通关评价只看命数**：还剩几架望远镜就是几分的评价——**三架全留 = 满分「完美观测」**。踩雷会白送一颗雷的位置，所以满分等于"整局没靠失误换信息"；88 关都能零猜测推完，满分永远可达。**关卡面板用星星展示成就**（三星 = 零失误，只显示历史最高，后续重玩变差也不掉星）；**重玩也计时**（第 11 关起同样限时，超时判负）；金色 ⏱ 是独立的时间达标标记，不参与评分。
- **每关一个真实星座**：猎户、天鹅、天蝎、仙后、天龙、武仙……揭晓时按**真实视星等**渲染星点大小与颜色，连线依次画出。
- **盘面按可玩性设计**：雷密度 18.4%–27.3%（均值 23.5%，后段收紧到 24.8%–27.3%）、除第 1 关入门盘外每行每列都有星、孤立雷 ≤2（避免"一眼就知道"）。
- **零依赖零联网**：全部内容在单个 `index.html` 内，双击即玩；无字体/图片/脚本外链。
- **星座图鉴（✦ 图鉴，88 个星座）**：每通关一关点亮一颗星座（**图鉴 88/88 即完整天球**）；按**真实天球投影**摆放（横轴赤经 0–24h、纵轴赤纬 ±90°），点开可看星图、方位、面积排名、最亮星与**真实相邻星座**（可互相跳转，共 200+ 条相邻关系）；支持滚轮/双指缩放与拖动星图，并提供「一键点亮（预览）」给评审/开发总览全部星座位置。
- **给评审的开关**：关卡面板里的「全部解锁」可直接跳任意关，不影响通关记录。

## 玩法细节

> 第一次打开是一张**入场页**（品牌 + 三行玩法要点 + 继续/重开 + 图鉴与音效角标），**一次点击**就能开始下棋。
>
> 🧭 **三个模式**（打开先见主页，一句定位 + 三张模式卡）：**闯关**（88 关主流程）·
> **限时关卡**（**第 11 关起超时即失败**，状态栏倒计时；限时从第一次操作才开始，目标时间内完成留**金色 ⏱**，
> 关卡面板里未解锁的限时关也带 ⏱）· **♾ 无尽冲分**（约 2 分钟一局，分数只增不减；独立存档，不影响闯关进度）。
> 顶栏主页按钮游戏中即**暂停菜单**。
>
> 🌐 **3D 天球图鉴**：图鉴里的 88 个星座按真实赤经/赤纬摆在一颗**可以转动的天球**上（天赤道环 + 银道带），
> 拖动即转、点开看海报；也可以一键切回 2D 平面投影。
>
> ✦ **星座海报**：点开图鉴里的星座，会看到一张深空海报（星座连线 + 星名标注 + 可见半球 / 最佳观赏月份），
> 左上角保留你在棋盘上拼出的那张小星图。
>
> 💬 **意见箱**：右上角「✉ 意见」可以直接写反馈。内容**只存在你自己的浏览器里**，点「复制反馈」或「导出 feedback.txt」才会离开浏览器；
> 想用邮件发我，点「✉ 查看作者邮箱」复制地址即可（页面本身不发任何网络请求）。


| 操作 | 说明                        |
| -- | ------------------------- |
| 观测 | 手机**轻触** / 电脑**单击**格子，翻开显示数字（即时） |
| 标记 | 手机**长按** / 电脑**右键**，标星 / 取消 |
| 目标 | 翻开全部安全格 + 标出全部星（标记或已踩爆都算） |
| 失败 | 踩到未标记的星 3 次，命数耗尽          |

进度存在浏览器 `localStorage`，换设备/清缓存会重置。

## 仓库结构

```
index.html                     # 发布版（单文件，可直接玩）
game/index.html                # UI 源文件（关卡数据由构建脚本注入）
tools/generate_levels.py       # 关卡生成器 + 逻辑求解器（零猜测可解验收）
tools/fit_constellation_levels.py  # 星座摆位拟合（密度/孤立雷/空行约束）
tools/sky.json                 # 图鉴数据（真实赤经赤纬/面积排名/相邻星座）
tools/build_sky.py            # 生成图鉴数据
tools/levels.json              # 关卡数据（星座星、杂星、行列线索、开局）
tools/build_release.py         # 打包：注入数据 → 校验 → dist + ZIP + manifest
dist/                          # 构建产物（index.html / build_manifest.json）
docs/SPEC.md                   # 规则与验收契约
docs/HANDOFF-关卡扩展.md         # 继续扩关卡的协作须知（流程/约束/已知坑）
冉政-设计思路文档.md            # 设计思路（竞赛文档）
冉政-迭代优化过程文档.md        # 迭代与验证记录（竞赛文档）
```

## 构建

```bash
python tools/fit_constellation_levels.py   # 生成/重排关卡（需要求解器验收）
python tools/build_release.py              # 注入数据、校验、打包
python tools/check_levels.py               # 关卡自检（可解性/孤立雷/空行/密度/图鉴覆盖）
python tools/sync_docs_tables.py           # 把两份文档里的关卡表同步成最新数据
```

## 技术

单文件离线 H5：原生 HTML/CSS/JS，无框架、无构建工具链依赖（仅用 Python 做关卡生成与打包）。棋盘与揭晓图都是 DOM + 内联 SVG，动画全部用 CSS keyframes，并尊重 `prefers-reduced-motion`。
