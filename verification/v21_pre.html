玩法规则

棋盘是夜空：把安全格全部翻开，并把所有的星都标出来，即通关。

两种线索
  1. 数字（扫雷）：格子上的数字 = 它周围 8 格里的星数。
  2. 行 / 列数字（数织）：棋盘上方与左侧的数字，表示这一列 / 这一行里「连续星块」的长度，按出现顺序排列。例如 2 1 = 两颗连着的星、至少空一格、再一颗星。
  3. 两者要一起用：多数关卡只靠数字推不完，只靠行列线索也推不完 —— 交叉推理才能定死一颗星。
怎么操作
  1. 手机 / 平板：轻触格子 = 观测；长按格子约 0.4 秒 = 标记 ★ / 取消标记（会有一点点震动）。
  2. 电脑（鼠标）：左键单击格子 = 观测；右键格子 = 标记 ★ / 取消标记。
  3. 键盘：Enter = 观测；空格 或 Shift+Enter = 标记。
  4. 防误触：按住后手指滑动超过约 12 像素，视为"在拖动页面"，不会触发观测或标记。
生命与杂星
  1. 共有 3 条命。观测到还没标记的星会掉一条命，同时把那颗星亮出来。
  2. 杂星：有些星并不属于本关星座（用来增加迷惑与密度）。它们同样是星，一样要标记；通关揭晓时不会出现在星座连线里。
通关与图鉴
  1. 翻开全部安全格 + 标出全部星 → 揭晓本关对应的真实星座，并在图鉴里点亮它。
  2. 图鉴（顶部星座连线图标）：按真实天球位置摆放星座（横轴赤经 0–24 时、纵轴赤纬 ±90°）。可按季节筛选、滚轮或双指缩放、按住拖动；点星座看详情（赤经赤纬、面积排名、最亮星、相邻星座可互相跳转）。
  3. 未观测的星座只显示暗色名字，观测过的会亮起并闪烁。
难度与公平性
  1. 不用猜：每一关都由逻辑求解器验证过「不靠运气也能推完」。
  2. 教学节奏：第 1 关只给扫雷数字（纯教学），第 2 关起才引入行列线索。

提示：翻开的数字是「周围有几颗星」，不是「周围有几颗杂星」——杂星与星座星在推理上完全等价。顶部 🔊 图标可随时开关音效。

✦ 怎么玩

翻开所有安全格、并把所有星标出来，这一关就通了。

手机：轻触观测、长按标记；电脑：单击观测、右键标记。

数字 = 它周围 8 格里有几颗星（0 会连锁翻开）。

📱 轻触 = 🔭 观测　长按 = ★ 标记　｜　💻 单击 = 🔭 观测　右键 = ★ 标记
手机：轻触格子 = 观测（翻开看数字），长按 = 标记 / 取消标记。电脑：单击 = 观测，右键 = 标记。
带行列线索的关卡会在左侧与上方显示“连续星块”的长度；把所有安全格翻开、所有星星标出，就能看见这一关的星座。进度自动保存在本机浏览器里。
