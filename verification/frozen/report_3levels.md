## 2. 生成器做了什么（可复现）

1. 随机布雷 → 计算每行/列的连续块线索与每个安全格的邻域雷数。
2. 选一个邻域雷数为 0 的格作为 `opening`（要求开局 flood fill 至少翻开 5 格）。
3. 模拟一个**只会做可靠推理**的玩家，交替执行：
   - **(a) 邻域计数传播**：数字 == 周围已插旗数 → 其余未知邻居全安全；数字 == 已插旗 + 未知邻居数 → 那些邻居全是雷；
   - **(b) 数织行/列枚举**：枚举该行/列所有与已知状态相容的连续块摆放，取交集 → 强制雷 / 强制安全格；
   每判定出一个安全格就翻开并触发 flood fill，直到全盘判定完毕（= 零猜测可完成）或卡住。
4. **分关卡条件**：第 1 关要求「只用 (a) 就能通关」且手动探格 ≥3 次；第 2、3 关要求「只用 (a) 会卡住、必须用 (b)」。
5. **唯一性（参考值，非闸门）**：以开局静态线索为准数解。**验收闸门是第 3 步的「零猜测可完成」**：可靠规则能推完全盘 ⇒ 结论被唯一确定。静态解数只作参考 —— 无连续块时用穷举，有连续块时逐行枚举 + 列前缀剪枝；后者在本机上枚举成本高（7×7 会指数爆炸），故含连续块的关卡标注「未测」，由 **T8 独立复核**用另一套实现另行验证。

> ⚠️ 已知局限：无连续块线索时（第 1 关）静态唯一性检查的剪枝最弱，超节点预算会标「未判定」；此时以「可靠推理可推完全盘」为主要依据（可靠规则能推完 ⇒ 解被唯一确定）。
